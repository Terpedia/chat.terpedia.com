# Terpedia Chat

The live application is the custom frontend served from the repository's `docs/` deployment, not LibreChat.

The frontend sends chat requests to `https://api.terpedia.com/api/chat`. The research workflow, LangGraph orchestration, prompts, and chemistry tools belong in that backend service.

Legacy LibreChat deployment files are preserved under `archive/librechat-legacy/` for reference and are not part of the active chat application.
